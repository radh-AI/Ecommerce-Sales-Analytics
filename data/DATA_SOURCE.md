## Dataset Description

This dataset contains simulated e-commerce transactions designed to represent realistic online retail operations.

It supports analysis of sales performance, customer purchasing behavior, product performance, regional trends, delivery operations, and business profitability.

The dataset is intended for educational, analytical, and business intelligence projects.



## Project Usage

This dataset is used in an end-to-end E-commerce Sales Analytics portfolio project involving:

1.Python (Pandas) for data cleaning and validation.

2.PostgreSQL for data storage, SQL analysis, and analytical views.

3.Power BI for interactive dashboard development.

4.GitHub for project documentation and portfolio presentation.
